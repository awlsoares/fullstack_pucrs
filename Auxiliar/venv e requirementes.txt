1) Baixar e instalar o PostgreSQL
2) Criar um banco de dados.
3) Alterar o arquivo app.py na seguinte configuração: 

app.config['SQLALCHEMY_DATABASE_URI'] = 'postgresql://essencial_v1:essencial_v1@localhost:5432/essencial_v1'

dialeto://usuario:senha@host:porta/nome_do_banco

4) Criar e ativar o ambiente virtual:
python3 -m venv venv (No Macbook)
source venv/bin/activate (No Macbook)

python -m venv venv (No Windows)
venv\Scripts\activate (No Windows)

5) instalar os requeriments
pip install -r requirements.txt

6) Iniciar e migrar o banco de dados

flask db init
flask db migrate -m "Migração inicial do banco de dados"
flask db upgrade


7) Rodar o programa:

python app.py



Extra)
    a) Para criar o arquivo requeriments.txt
        pip freeze > requirements.txt

    b) Para instalar o arquivo requeriments.txt
        pip install -r requirements.txt
