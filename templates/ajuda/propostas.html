Ajuda - Propostas

  • Criação de uma Proposta

Criação de uma Proposta

  • Para criar uma nova proposta, clique em "➕ Nova Proposta" no menu.
  • Preencha os campos obrigatórios, como cliente, valor e descrição.
  • Após salvar, a proposta ficará com o status inicial "Aguardando Aprovação".

Alteração de Status da Proposta

  • Proposta "Aguardando Aprovação": é permitido mudar o status.
  • Proposta "Aprovada": não é permitido mudar o status caso exista um contrato associado.
  • Proposta "Reprovada": é permitido mudar o status.
  • Quando você altera o status da Proposta para "Aprovada", surgirá o botão ➕ na coluna "Contrato". Se você clicar em ➕ o sistema abrirá uma tela para cadastro de um novo Contrato.
    Para propostas cadastradas como Múltiplos Contratos o botão ➕ sempre estará disponível enquanto a Proposta estiver ativa.
    Para propostas de contratos únicos, quando você cadastrar o novo Contrato o botão ➕ ficará oculto.

Cancelamento de uma Proposta

  • Só é permitido cancelar uma proposta se a mesma estiver com o status Aguardando Aprovação ou com o status Aprovada (desde que não tenha um contrato associado).
  • Para cancelar a proposta clique no ícone de Status ( ● / ● ) e selecione a opção Cancelar.
  • A operação de cancelamento de uma proposta não poderá ser desfeita.
  • Observação: o número de uma proposta cancelada fica indisponível no sistema.

Criação de um Contrato

  • Um contrato só pode ser criado a partir de uma proposta aprovada.
  • No menu da proposta, clique em "Criar Contrato".
  • Preencha os dados necessários e confirme para vincular o contrato à proposta.
